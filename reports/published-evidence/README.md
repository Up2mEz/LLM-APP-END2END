# หลักฐานสำหรับตรวจคำนวณคะแนน

ไฟล์ `.jsonl.gz` เป็นผลดิบจากสองรอบทดลองที่ระบุในชื่อไฟล์ บีบอัดโดยไม่เปลี่ยนเนื้อหา ตรวจค่า SHA-256 ทั้งก่อนและหลังบีบอัดได้จาก `manifest.json` รวมข้อความหลักฐานและผลตอบสำหรับตรวจย้อนหลัง ไม่มี API key หรือข้อมูลผู้ป่วยเฉพาะบุคคลในไฟล์ชุดนี้

รัน `python scripts/verify_published_results.py` จากราก repo หลังติดตั้ง dependencies เพื่อคำนวณคะแนนการค้น คะแนนคำตอบ และผลเปรียบเทียบ agent จากไฟล์เหล่านี้ คำสั่งไม่เขียนทับผลประเมิน ไม่โหลดโมเดล และไม่เรียกบริการภายนอก

นี่คือการคำนวณซ้ำจากผลที่บันทึกไว้ การสร้างคำตอบใหม่ต้องเตรียมข้อมูลและ class proxy ตาม README และอาจได้คะแนนต่างจากเดิม ส่วนผู้ตรวจคำตอบ GPT-6-Luna เป็น LLM-as-judge ไม่ใช่ผู้เชี่ยวชาญทางคลินิก
