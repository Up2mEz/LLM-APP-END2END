# Proposal

โปรเจคนี้พัฒนาผู้ช่วยค้นหลักฐานจากเอกสารแนวทาง NCD ภาษาไทยสำหรับนักศึกษาและผู้ที่ต้องอ่านเอกสารหลายฉบับ โดยนำ corpus, gold และ hybrid retrieval จากโปรเจค Thai NCD ของทีมมาใช้ต่อ แล้วเพิ่ม Gemma ผ่าน class proxy ให้เรียก search_docs ใน agent loop และตอบพร้อมข้อความอ้างอิงและเลขหน้า ระบบมี schema validation และ stop condition เพื่อจำกัดการค้นและไม่แสดงคำตอบที่อ้างแหล่งข้อมูลที่ไม่มีจริง ประเมิน retrieval ด้วย Strict Recall@5 และ MRR@10 เทียบ dense baseline พร้อมประเมินการตอบและงดตอบบน dev sample ที่ล็อกไว้ 30 ข้อ แสดงทั้งกรณีสำเร็จและกรณีหลักฐานไม่พอผ่านหน้าเว็บ โดยระบุข้อจำกัดเรื่องความถูกต้องเชิงความหมายและสิทธิ์เผยแพร่ corpus อย่างชัดเจน

สถานะ: ร่างสำหรับผู้ใช้ตรวจและนำไปยืนยัน scope กับผู้สอน ยังไม่ได้อ้างว่าผู้สอนอนุมัติ proposal นี้
