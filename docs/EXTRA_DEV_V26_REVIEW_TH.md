## การแก้หลังเห็นผลชุดนี้

การแก้เหล่านี้เป็น **development tuning บนชุด extra-dev ที่เปิดผลแล้ว** จึงห้ามเอาผล v26 มาอ้างว่า v27 ดีขึ้นจริงก่อนทดสอบ v27 ใหม่ และแม้ v27 ดีขึ้นบน 30 ข้อเดิม ก็ไม่ใช่ผล generalization อิสระ

- เพิ่มการจับ HTML table และรักษาหัว/แถวไม่ให้ passage focus ตัดคนละหน้า; ตัวอ่านปีและคอลัมน์ remission ต้องเห็นชื่อคอลัมน์กับแถวจริงก่อนตอบ
- เพิ่ม lexical exact admission สำหรับฟิลด์ที่ผู้ใช้ถามว่าแยกบันทึกหรือไม่ โดยตรวจข้อความจาก frozen parent จริง ไม่แก้ index; มี route ที่อ่านประโยคแยกน้ำหนักและส่วนสูงเมื่อพบตรง
- ตรวจระดับหลักสูตรและ edition ก่อนอ่านระยะเวลา ไม่ปน “ระดับกลาง II” กับ “ระดับกลาง”
- ปรับ quantity guard ไม่ให้นับ “กี่” ใน “เกี่ยวข้อง” และให้รับ grade แบบ `III B`
- ถ้า Gemma ส่ง claims ซ้ำหลายอัน ให้คงเฉพาะ claim ที่คัดตรง source เดิม แต่ยังต้องผ่าน reviewer; ถ้า citation line ที่ Gemma เดาผิด ให้ซ่อมได้เฉพาะกรณีคำตอบทั้งประโยคตรงกับ source ที่ Gemma เลือกอยู่แล้ว
- ป้องกันการย้ายคำแนะนำข้ามชื่อยา, ข้าม population ของ BMI และจากแนวทางอาหารเด็กทั่วไปไปยังเด็กที่มีเบาหวานร่วม CKD
- เก็บ comparator ก่อนหน้าจากเอกสาร edition เดียวกันและตรวจว่าคำตอบเปรียบเทียบตอบทั้งสองกรณี

Unit tests ใช้ค่า/เอกสารสังเคราะห์ที่เปลี่ยนตัวเลขและมี negative cases; serving code ไม่อ่าน qid, gold หรือ reference answer ผลหลังแก้ต้องดู `docs/DEV_COMPARISON_TH.md` และรายงานรุ่นใหม่แยกจาก baseline นี้
