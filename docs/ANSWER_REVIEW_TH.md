# ตรวจคำตอบ dev v8 เทียบ reference

ตรวจจากผลจริงทั้ง 30 ข้อโดย coding agent ไม่ใช่แพทย์หรือ independent clinical validation ชุดนี้ใช้พัฒนาแล้ว จึงไม่ใช่ held-out test ไม่ส่ง reference ให้ Gemma และไม่ได้แก้ gold หรือ retrieval เพื่อเพิ่มคะแนน

## ผลล่าสุดและ trade-off

v8 ตอบ 11 ข้อ งดตอบ 19 ข้อ ใน 11 ข้อที่ตอบ มี 9 ข้อที่สาระหลักตรง reference และอีก 2 ข้อที่ยังต้องตรวจบริบท/ความครบถ้วน ใน 19 ข้อที่งดตอบ มี 5 ข้อที่ตรง unanswerable label และ 14 ข้อที่จริง ๆ มีคำตอบใน gold

v5 ตอบ 18 ข้อ มีคำตอบผิดชัดเจนเรื่องค่าตารางใน q113/q080 และตอบทั้งที่ไม่มีจำนวนที่ถามใน q120 รุ่นล่าสุดระงับทั้งสามกรณีได้ แต่ไม่ได้ทำให้โมเดลอ่านตารางถูก และยังทำให้คำตอบที่เคยตรง reference ถูกงดตอบเพิ่ม 4 ข้อ คือ q017/q068/q101/q106 จึงไม่อ้างว่า overall accuracy ดีขึ้น

## สาเหตุและลำดับปรับปรุง

1. ทำ context ของตารางให้คงหัวแถว หัวคอลัมน์ หน่วย และชื่อเรื่องก่อนให้ model อ่าน ต้อง version เป็น enrichment แยกจาก frozen retrieval เดิม แล้ววัดบน dev เดิม ไม่แก้ gold ตามคำตอบ
2. ลด false abstention จาก reviewer ที่คัดข้อความผิด โดยทดลองเลือก evidence spans ด้วย ID/offset จากข้อความที่ให้ แทนให้ model พิมพ์ quote ใหม่ พร้อมตรวจว่าไม่ได้ปล่อย unsupported claims มากขึ้น
3. แยกประเด็นย่อยและบริบทของคำถาม เช่นโรค กลุ่มอายุและชนิดตัวเลข ให้ชัดก่อนสร้างคำตอบ; quantity guard ปัจจุบันตรวจได้เพียงว่ามีตัวเลข/คำจำนวน ไม่ได้ตรวจว่าจำนวนถูกต้อง
4. ทบทวน gold ที่กำกวมกับผู้ตรวจข้อมูลโดยไม่เปลี่ยน label เพื่อเข้าข้างโมเดล โดยเฉพาะ q041 และ alternative evidence
5. ให้ผู้มีความรู้ตรวจ claim-level correctness และใช้ชุดคำถามใหม่ที่ยังไม่เคยปรับ prompt ก่อนอ้าง generalization
