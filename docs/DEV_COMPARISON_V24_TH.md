# ตรวจคำตอบ v24 เทียบ v13 บน dev 30 ข้อเดิม

แก้แล้วถูกเพิ่มสุทธิ **7 ข้อ**: สาระครบตามเกณฑ์ตรวจ 14 → 21 จาก 25 ข้อที่ gold มีคำตอบ แก้ถูกเพิ่ม 8 ข้อ แต่ q115 ถอยหลัง 1 ข้อ ยังไม่ผ่านทั้งหมด ไม่แก้ gold และไม่แก้ repo ต้นทาง

การตรวจนี้ทำโดย coding agent จากคำตอบจริง reference และ evidence ใช้เกณฑ์เข้มงวดเดียวกับ baseline เป็น exposed dev ที่ใช้พัฒนาหลายรอบ ไม่ใช่ held-out test หรือการรับรองทางคลินิก

ถูกเพิ่ม: q126, q041, q108, q099, q075, q098, q101, q076. Regression: q115 จากตอบถูกเป็นงดตอบเพราะ verifier protocol. จำนวน false abstention จึงไม่ลดสุทธิ แม้ q075 หายแล้ว เพราะ q115 เข้ามาแทน q061 ที่ยังไม่ผ่าน

ถ้านับการงดตรง label รวมด้วย ได้ 19 → 26 จาก 30 แต่ไม่เรียกตัวเลขนี้ clinical accuracy: q120 และ q118 หยุดจาก validation/review gate ส่วนการงดตรง label ไม่พิสูจน์เหตุผลด้วยตัวมันเอง Citation metric และ Character F1 ก็ไม่ใช่ answer accuracy

## สิ่งที่ยังไม่ผ่านและแนวทางถัดไป

- q061: ยังวนคำตอบให้อ่านฉลาก ทั้งที่โจทย์ถามว่าดูข้อมูลอะไร ต้องปรับการเลือก field จากข้อความให้ได้ชื่อข้อมูลโดยตรง และทดสอบกับฉลากชนิดอื่นด้วย
- q115: มีหลักฐาน round 2 / PDCA แต่ claim-source binding ของ reviewer ไม่ผ่าน ต้องลดความซับซ้อนของ reviewer protocol โดยไม่ยอมให้ ID ผิดหลุด
- q111: คำตอบมี quarter plate และแป้งโปรตีนต่ำแล้ว แต่ยังไม่ผูกการปรับกับ CKD ชัด ต้องแยกคำถามหลายเงื่อนไขก่อนประกอบคำตอบ
- q106: ค่าที่ต้องการมีอยู่ แต่ควรเลือกเฉพาะเป้าที่ตรง proteinuria condition และตัดเกณฑ์ทั่วไปออก การจัด partial ใช้เกณฑ์อนุรักษ์นิยม ไม่กล่าวว่าค่าที่คัดมาทั้งหมดผิด

ยังพบคำซ้ำ/สะกดจาก OCR และคำตอบตารางยาวกว่าจำเป็น จัดเป็นงาน readability แยกจาก core correctness

## การทำซ้ำและข้อจำกัด

ล็อก qids, gold/table hashes, model, temperature และ implementation ก่อนรัน เก็บ private/runs/gemma-dev-v24/answers.jsonl ครบ 30 ข้อ พร้อม sources/citations/trace ไม่แก้ผลที่ล้มเหลว และไม่มี qid/reference lookup ใน serving

v24 บันทึก 8 HTTP attempts ใหม่ ใช้ response cache เมื่อ payload ตรง ส่วน v13 ใช้ outputs จาก v12 และไม่มี HTTP attempts ใหม่ จึงไม่อ้างว่าเป็น independent repeat generation ทั้ง 30 ข้อ เก็บทุก candidate v14–v24 รวม v14 ที่หยุดหลัง 9 ข้อ และรุ่นที่แย่ลงไว้ด้วย อ่าน reports/agent_comparison.json

Tests 135 ผ่าน ไม่มี failed/error/skipped เป็น synthetic unit/API tests แยกจาก dev evaluation จริง มี Starlette deprecation warning 1 รายการ ไม่ติดตั้ง package เพิ่มในรอบนี้

ตรวจ source allow-list 48 ไฟล์และ PDF ที่อ่าน 33 ไฟล์ด้วย SHA-256 ไม่เปลี่ยน ไม่ใช่ whole-repository clean-tree claim. Gold SHA-256: 680a752e738d7a60f463345c08e3e098934ab945df2183a8bb1e0d97b1f6ddea
