## คำถามผู้ใช้เรื่องโรคไต

ทดสอบข้อความเดิม “เป็นโรคไต ควรงดกินไร” โดยแยกจาก dev 30 ข้อ ใน v8 ค้นได้ 5 แหล่ง แต่ answer JSON ผิดรูปแบบ จากนั้นรอบซ่อมเปลี่ยนเป็นงดตอบ จึงไม่ใช่กรณีไม่มีเอกสาร

v13 ตอบคำแนะนำทั่วไปเรื่องอาหารเค็มจากเอกสาร ckd-public-kidney-prevention-tips หน้า PDF 69 และชี้แจงว่ายังไม่ทราบระยะโรค ผลเลือด และการฟอกไต จึงยังระบุรายการอาหารที่ต้องงดเฉพาะตัวไม่ได้ ไม่เหมารวมให้งดโพแทสเซียม ฟอสฟอรัส ผัก ผลไม้ หรือนมทั้งหมด ทดสอบผ่าน API และหน้าเว็บจริง

อาหารและข้อจำกัดเฉพาะบุคคลขึ้นกับข้อมูลทางคลินิก สอดคล้องกับ [NIDDK: Healthy Eating for Adults with CKD](https://www.niddk.nih.gov/health-information/kidney-disease/chronic-kidney-disease-ckd/healthy-eating-adults-chronic-kidney-disease) ซึ่งใช้ตรวจแนวทางการตอบในรายงานนี้ ไม่ได้เพิ่มเว็บดังกล่าวเข้า frozen corpus หรือ gold
