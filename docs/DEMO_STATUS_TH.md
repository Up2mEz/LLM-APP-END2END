# สถานะคลิปสาธิต

คลิปฉบับปรับสัดส่วนมีความยาว 246.2 วินาที (4 นาที 6 วินาที) ความละเอียด 1920 × 1080 พร้อมเสียง Arlo และคำบรรยายไทย ใช้ภาพเว็บประกอบ motion graphic อธิบายระบบและผลประเมิน

ช่วงเว็บของฉบับนี้นำผลตอบที่บันทึกไว้มาแสดงผ่าน frontend จริงในหน้าต่าง 1260 × 650 มีป้าย REPLAY ไม่มีการเรียกโมเดลใหม่ ตัวกรอบวิดีโอไม่ครอปหรือยืดภาพเว็บ จึงไม่ควรใช้คลิปนี้ยืนยันว่าได้ทดสอบ backend สดในวันบันทึกภาพใหม่ หรือใช้ผลเดโมแทนผลของชุดประเมิน

ตัวอย่างแสดงคำตอบเรื่องระยะเวลาออกกำลังกาย การตรวจคำตอบกับบริบทหลักฐาน และการงดตอบคำถามชื่อยาที่สมมติขึ้น ผลประเมินใน motion graphic อ้างอิงรอบที่ระบุใน README แยกจากตัวอย่างเดโม
